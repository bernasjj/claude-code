# CLAUDE.md

Instruções de projeto para a agência de web design.

## Regra: padrão de websites de clientes

**Sempre que iniciares um novo projeto de website para um cliente desta agência,
lê e aplica [`docs/premium-website-blueprint.md`](docs/premium-website-blueprint.md)
como padrão de referência.**

- Segue a estrutura de página, os princípios de design e as convenções desse
  blueprint do início ao fim.
- Valida sempre a entrega com a **checklist de entrega** (secção 9 do blueprint)
  antes de considerar o site pronto.
- **Stack por defeito:** HTML / CSS / JavaScript puro (sem framework), salvo
  indicação em contrário do cliente.

Se o cliente pedir explicitamente outra abordagem, essa instrução do cliente tem
prioridade — mas continua a usar o blueprint como base de qualidade.
